## 🚀 What's New in v0.5.1

- **Recurring Tasks Engine (Periodicity)**:
  - Presets (Daily, Weekly, Bi-Weekly, Monthly, Yearly) and custom intervals.
  - "Spawn on Completion" rollover strategy: automatically spawns next active instance upon completion.
  - Recurrence badge, picker sheet, and indicator.
- **Multi-Task AI Resolution & Voice Disambiguation**:
  - Needle AI engine extracts multiple tasks from a single voice input.
  - Multi-target conversational questionnaire for missing metadata.
  - Fallback local heuristic parser support.
- **Offline Sync & RBAC**:
  - Offline mutations via local Hive store with automatic synchronization.
  - 2-comment limit rule per task lifecycle.

## 📲 Installation Instructions

### Android
1. Download [`Waypoint-v0.5.1.apk`](releases/Waypoint-v0.5.1.apk).
2. Allow installation from unknown sources if prompted.
3. Open the APK to install or update Waypoint.

### Windows
1. Download [`Waypoint-v0.5.1-Setup.exe`](releases/Waypoint-v0.5.1-Setup.exe).
2. Run the installer wizard.
3. Launch Waypoint from the Start Menu or desktop shortcut.
